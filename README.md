## What I build

## Selected work

> [!NOTE]
> Educational projects, built to be reproducible and upfront about their limits. Nothing here is investment advice or a performance claim.

### Research and modeling

- **[`personal-quant-research`](https://github.com/grisheet/personal-quant-research)** — A framework for systematic equity research: point-in-time data, self-financing backtests, and reproducible reports. The bundled demo uses synthetic data and makes no alpha claim.
- **[`mock-lbo-energizer`](https://github.com/grisheet/mock-lbo-energizer)** — A hypothetical leveraged buyout of Energizer, built as a linked Excel model and checked against an independent Python engine.
- **[`corporate-guidance-revision-db`](https://github.com/grisheet/corporate-guidance-revision-db)** — A PostgreSQL and Python pipeline with a Dash dashboard for studying how stocks react to guidance revisions, running on sample data.

### Applications

- **[`dividend-sustainability-analyzer`](https://github.com/grisheet/dividend-sustainability-analyzer)** — A FastAPI app that scores dividend safety from 0 to 100, with visible thresholds and a plain-English reason behind every rating.
- **[`block-trade-monitor`](https://github.com/grisheet/block-trade-monitor)** — A Next.js and Python dashboard exploring block-trade and dark-pool activity, where every score traces back to its inputs. Runs on seeded mock data.

### Security

- **[`sigma-detection-engineering`](https://github.com/grisheet/sigma-detection-engineering)** — Eight Sigma rules mapped to MITRE ATT&CK, covering PowerShell, credential access, lateral movement, and persistence. Experimental.
